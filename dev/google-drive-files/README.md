## Setup

### gem install

```console
$ gem install google-apis-drive_v3
```

### Google service account

1. Create a service account
   * https://docs.cloud.google.com/iam/docs/service-accounts-create
2. Create a key and download the JSON file
   * https://docs.cloud.google.com/iam/docs/keys-create-delete#creating
3. Set the path of the downloaded JSON file to the environment variable `GOOGLE_APPLICATION_CREDENTIALS`
   * ```console
     # Bash example
     $ export GOOGLE_APPLICATION_CREDENTIALS=/path/to/service_account_json_key.json
     ```

## Generate file ids

Usage:

```
Usage: ./generate-file-ids.rb NEXT_VERSION
```

Example:

```console
$ ./generate-file-ids.rb 2.0 > file-ids.tsv
$ head -n 3 file-ids.tsv
1mP0gDFgGaX6Ufobr8ocyg71ccsYgfBDw	OpenArm 2.0/Options/OpenArm_2.0_w_Head_Camera.STEP
15p1PYmEKcDmnYQ5Hy_trM8gIoFCADF5a	OpenArm 2.0/OpenArm 2.0 BOM.xlsx
1aU-V3lt_aPrZoRM8FFx6dMQu2f28Ws0I	OpenArm 2.0/OpenArm_2.0.STEP
```

Only files in the `Hardware/` directory of the specified version
such as `v2.0/Hardware/` are included. `v2.0/` and `Hardware/` are
omitted from the path.

## `file-ids.tsv`

This is a commit of file automatically generated by `generate-file-ids.rb`.
If changes are made to Google Drive, please run `generate-file-ids.rb` and commit the changes.

Each line has the following tab-separated columns:

1. Google Drive file ID
2. Path in the release archive
3. (Optional) MIME type of Google Workspace files such as
   `application/vnd.google-apps.document` (Google Docs). The release
   job exports Google Docs as PDF and the path in the second column
   has `.pdf` suffix. Other Google Workspace files (Sheets, Slides and
   so on) aren't supported yet and `generate-file-ids.rb` skips them.
